⚠️

Cannot Run Directly via file:// Protocol

Modern browsers enforce strict CORS security policies that block local ES modules (<script type="module">) when loaded from file:/// paths.

# To launch OpenComp with full hardware acceleration:
run_desktop.bat

# Or start the local HTTP server manually:
node server.js
Then visit: http://127.0.0.1:8080/

Never disable browser security flags globally. Always use OpenComp's local HTTP server (bound exclusively to 127.0.0.1).
